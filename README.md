**Web and mobile development (Sep 2026)**
I built *Prenumerationskollen*, an app for keeping track of subscriptions like Netflix and Spotify. One ASP.NET Web API (.NET 10) serves both a React + Vite web client and a React Native / Expo mobile app. You can upload logos and receipts, and the API checks file type and size before saving anything. I kept the data in memory on purpose so the whole thing starts with `dotnet run`, no database setup.
